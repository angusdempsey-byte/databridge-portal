Logic Keys
Columns that drive the logic
Back Orders & Open Orders Report
Item No.
?
Item No.The internal material/item number used to link demand rows to inventory stock and purchase order lines. This must match the Item No. in the Inventory List and Purchase Lines files.
Links to inventory & PO lines
Outstanding Qty
?
Outstanding QtyThe quantity still to be delivered for this order line. Used in the FIFO allocation to determine how much inventory or incoming stock is needed to fill each order.
Quantity to fill (col Z)
Order Date
?
Order DateThe date of the original order. Used to sort demand oldest to newest before FIFO allocation — older orders get filled before newer ones.
Oldest → newest sort (col V)
External Doc No.
?
External Doc No.The customer's purchase order number. Used as one half of the composite key to match rows in the customer report/template. Must match the PUR.DOC column in the output.
Match key for output template
Item Ref No.
?
Item Ref No.The item reference number used by the customer. Used as the second half of the composite key to match rows in the customer report/template. Must match the MATERIAL column in the output.
Match key for output template
Inventory List
Item No.
?
Inventory Item No.The item number in the inventory list. If an Item Reference List is loaded, the demand row's Item Ref is translated to an Item No. via the dictionary before checking this column.
Matched to Source Item No.
On Hand Qty
?
On Hand QtyThe quantity currently in stock. Inventory is checked first in the FIFO allocation — stock is drawn down before any purchase order dates are used.
Available stock to draw from
Purchase Lines
Item No.
?
PO Item No.The item number on the purchase order line. Matched against the source document's Item No. to find which PO lines supply each order.
Matched to Source Item No.
PO Qty
?
PO QtyThe outstanding quantity on this purchase order line. Lines with zero quantity are automatically skipped. Supply is drawn from PO lines oldest to newest until the order quantity is met.
Available supply qty (col N)
Delivery Date
?
Delivery DateThe expected arrival date for stock on this PO line. PO lines are sorted oldest to newest by this date. The date written to the output reflects the last PO drawn from to complete an order.
Expected arrival (col Q)
Item Reference List
Item Ref column
?
Item Ref columnThe item reference number in the dictionary. When checking inventory, the demand row's Item Ref is looked up here to find the corresponding Item No., ensuring accurate stock matching.
The reference to look up
Item No. column
?
Item No. columnThe item number that the Item Ref maps to. This resolved Item No. is used to look up available stock in the Inventory List.
The item number it maps to
Customer Report/Template
PUR.DOC column
?
PUR.DOC columnThe column in the customer report that holds the purchase order / external document number. Used to match source rows against existing rows in the output.
Matched against Ext Doc No.
MATERIAL column
?
MATERIAL columnThe column in the customer report that holds the item/material reference number. Used alongside PUR.DOC as the composite match key. Not required in Single Key match mode.
Matched against Item Ref No.
